**为什么它整体符合《剧本》的写作规范**

- 不写场号：正文没有 `1.`、`2.` 之类的制片场号。
- 几乎没有转场；少数 `CUT TO` / `FADE` 作为动作行处理。
- 标题页只有片名和作者（本库去掉了 PDF 上的 `FINAL DRAFT`）。
- 只写主场景：动作/事情 + 角色名 + 插入说明 + 对白，人物靠动作和台词立起来。
- 全剧 101 页，接近书里说的 100 页标准。

**少量例外**：剧本开头和结尾保留了 `we slowly zoom in`、`close-up` 等镜头语言；书里说这类术语应尽量避免，只留极少数非提不可的例外。本库把它们当动作/事情处理，没有新增镜头元素。

**Sintel 为什么不再作为库中案例**：它是 final polish / 制作稿，带场号、镜头提示和 `CUT TO`，适合观察动作密度与视觉叙事，但不适合作为写作稿的格式模板。它保留在下面的开放剧本清单里，供需要制作稿参考时阅读。

## 可以合法复用的开放剧本

- **Blender Studio 开放电影**：Sintel、Elephants Dream、Big Buck Bunny、Cosmos Laundromat、Spring、Coffee Run、Charge、Wing It! 等。影片与制作资料按 Creative Commons Attribution 发布，项目页的 **Script / Production files** 里常有剧本、beat sheet、step outline。它们多是制作稿（带场号、镜头提示），适合看视觉叙事与动作密度；如果要练写作稿格式，先按《剧本》的原则去掉这些制作标记。
- **公有领域影片的剧本**：如 *Night of the Living Dead*、*His Girl Friday*、*Charade*、*Detour* 等。注意：影片进入公有领域**不等于**其文学剧本也进入公有领域；正式使用前要单独核对剧本的版权状态。

## 这些案例对格式的启发

1. **场景标题是版面的骨架**：编号、内外景、地点、时间四件事要在一行里读完。
2. **动作段落按「一个视觉节拍」分段**，不按句子分段；动画尤其依赖可画出来的动作。
3. **对白块要短**：角色名、插入说明、台词三层缩进清楚，读者才能一眼扫过。
4. **蒙太奇、闪回、插入镜头**用场景内的动作小段处理，不必为每个镜头新建场景。
5. **初稿不需要制片场号**；场号是进入筹备后的工作标记，写作阶段交给场次索引即可。
6. **先分清写作稿和制作稿**：有场号、镜头角度、`CUT TO` 的，通常是制作/拍摄稿；新手先读无这些标记的写作稿，再看出品稿，才不会把制作细节当成写作规范。
